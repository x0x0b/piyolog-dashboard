# ぴよログ かんたんダッシュボード

ぴよログの公式Data Feedをブラウザ内で読み込み、直近24時間の育児記録を見やすく表示する非公式ダッシュボードです。

このプロジェクトはぴよログ公式とは関係のない個人開発のOSSです。ぴよログの名称は連携先を説明する目的で使用しています。公式のロゴや画面素材は使用していません。

## 対応範囲

無料版のData Feedだけで利用できます。MVPは `24h` Feedを対象にしており、3日・7日・28日のFeedや長期間の履歴保存には対応していません。Feedの発行と管理はぴよログアプリで行います。このツールからFeedは発行できません。

## Feed URLを用意する

ぴよログアプリの設定で「データフィード」を開き、新しいFeedを作成します。取得期間に24時間を選び、詳細画面の「フィードURLを表示」からURLをコピーしてください。そのURL全体を本アプリの入力欄へ貼り付けます。アプリからコピーしたURLをそのまま使い、パスやクエリを編集しないでください。

無料Feedは作成から90日で期限切れになります。ぴよログの仕様上、24時間Feedのキャッシュ保持時間は約1分です。このアプリはダッシュボードを表示中に約1分間隔で自動更新し、非表示のタブでは更新を止めます。一時的な接続エラー時は前回のデータを表示して自動再試行し、Feedの期限切れ・失効など再試行できないエラーでは自動更新を止めてエラーを表示します。

作成方法やData Feedの現行仕様は[ぴよログ公式Data Feed仕様](https://www.piyolog.com/app/piyolog/data_feed/ja/)を確認してください。

## 主な機能

- ダッシュボード表示中の約1分間隔の自動更新（タブを非表示にすると停止）
- 前回の粉ミルク記録に設定間隔（5分刻み）を加えた目安時刻
- 今日と直近24時間を分けたミルク集計、回数、平均量、平均間隔
- おしっこ・うんちの回数と最終時刻
- 粉ミルクと搾母乳を別々にした集計、母乳の基本的な回数・時間表示
- 24時間以内のミルク量グラフと、母乳・ミルク・排泄・睡眠のタイムライン（PCはホバー、スマホはタップで詳細を表示）
- システム設定に応じたライト・ダークテーマ
- 開発時にFeed URLなしで確認できる架空のサンプルデータ

## プライバシー

- サーバー、データベース、ユーザー登録はありません。GitHub Pages上の静的ファイルだけで動作します。
- Feed URLはブラウザから `https://feed.piyolog.com` へ直接GETし、このアプリの運営者や別の外部サービスへ転送しません。「この端末に保存する」は初期状態でオンです。保存しない場合はチェックを外してください。
- 育児記録はブラウザのメモリ内だけで扱い、localStorage・IndexedDB・サーバーへ保存しません。画面を閉じると読み込んだ記録は保持されません。
- Analytics、エラー報告、広告、外部JavaScript CDN、Push通知は使用しません。メモは画面に表示しません。

ブラウザから使う場合、Feed URLはぴよログへ送信するリクエストの宛先になります。共有端末ではFeed URLを保存せず、利用後にブラウザのサイトデータも確認してください。

## ローカル開発

Node.js 24 LTSとnpmを使用します。

```sh
npm ci
npm run dev
```

開発サーバーの設定画面で「サンプルデータで表示を試す」を選ぶと、架空のデータでダッシュボードを確認できます。サンプルには実在する個人情報を含めていません。

次のコマンドでテスト、lint、production buildを実行できます。

```sh
npm test
npm run lint
npm run build
```

## GitHub Pagesへのデプロイ

GitHub上に `piyolog-dashboard` という名前のリポジトリを作成し、このリポジトリをpushしてください。GitHubの Settings > Pages でビルド元を「GitHub Actions」に設定します。`main` ブランチへのpushでGitHub Actionsがテスト・lint・buildを実行し、成功するとGitHub Pagesへデプロイします。Actionsタブから手動実行することもできます。

Viteのproduction buildは `/piyolog-dashboard/` をbase pathとして出力します。Feed URLをソースコードやrepositoryへ入れず、公開ページにも貼り付けないでください。
